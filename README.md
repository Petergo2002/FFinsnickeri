# Mallastro

Static Astro website for Mallastro.

## Stack

- Astro
- Tailwind CSS
- TypeScript

## Development

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

## Validation

Run the Astro checks:

```bash
npm run check
```

Build the production site:

```bash
npm run build
```

## Notes

- Generated output folders such as `dist`, `.astro`, and `node_modules` are ignored.
- Reference/export folders are kept in the repo but excluded from TypeScript checking.
